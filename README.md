# Rei Pharma

## Nisja

```bash
npm install
npm run dev
```

Hapet në http://localhost:4321

## Struktura

- `src/config/site.ts` — të gjitha të dhënat e biznesit (telefon, orar, adresë, kategori)
- `src/styles/global.css` — token-at e ngjyrave dhe tipografisë
- `src/layouts/Base.astro` — SEO, fontet, JSON-LD
- `src/components/` — Header, Footer, HeroFlourish
- `src/pages/` — faqet

## Çfarë mungon në public/

- `logo-full.svg` — logoja e plotë, sfond transparent
- `logo-mark.svg` — vetëm R-ja
- `favicon.svg` — 512x512, vetëm R-ja
